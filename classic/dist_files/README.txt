Pellaeon Classic - talk to UCSF Chimera 1.x in plain English

1. Install Python 3.9 or newer from python.org (Windows: tick "Add Python to PATH").
2. Install Ollama (ollama.com) for a free local model, or have an API key ready (Gemini has a free tier).
3. Windows: double-click "Start Pellaeon Classic.cmd".   macOS: double-click "Start Pellaeon Classic.command".
   Linux: ./start.sh
   A small window opens (status, Launch Chimera, activity log) and your browser opens the Pellaeon panel.
4. In the small window press "Launch Chimera" (it starts Chimera with its REST server and connects), or start
   Chimera yourself, open Tools > Utilities > RESTServer, and type the port shown in its Reply Log, then press Test.
5. In the browser panel choose your AI provider once (Settings), then just type what you want.
Optional:  python install.py   puts a "Pellaeon Classic" shortcut on your desktop / Start menu.
